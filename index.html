Changer le mot de passe enseignant

Le mot de passe est enregistré dans le fichier sous forme d'empreinte (un nombre), pas en clair. Pour le changer, il faut remplacer cette empreinte dans le fichier.

Empreinte du nouveau mot de passe :

  1. Sur GitHub, ouvrez index.html puis cliquez sur le crayon (« Edit this file »).
  2. Faites Ctrl + F (Cmd + F sur Mac) et cherchez EMPREINTE_MOT_DE_PASSE.
  3. Juste avant ce mot, remplacez l'ancien nombre par le nouveau.
  4. Cliquez sur « Commit changes », attendez une minute ou deux, puis testez le nouveau mot de passe.

1. La température

La température mesure à quel point il fait chaud ou froid.

2. La pression

La pression, c'est la force avec laquelle l'air appuie sur tout ce qu'il touche.

Pression

Plus il y a d'air, plus il appuie fort : la pression augmente.

L'air est invisible : ici, on le dessine en petits ronds bleus.

3. La pression sur les planètes

Plus une planète a d'air au-dessus de son sol, plus la pression y est forte.

L'air est invisible : sur le schéma, on le dessine en bleu.

4. L'eau change d'état

Quand la température ou la pression change, l'eau peut changer d'état : solide, liquide ou gaz.
